# Calculator Debug APK (22 MB)

The debug APK for **Calculator** has been built and placed in multiple direct locations within your workspace:

### File Locations in Your Workspace:
1. **`Calculator.apk`** (in the project root directory)
2. **`app/Calculator.apk`** (inside the `app` folder)
3. **`app/src/main/assets/Calculator.apk`** (inside `app/src/main/assets/`)
4. **`app/build/outputs/apk/debug/app-debug.apk`** (the standard Gradle build output)

### Direct Download Options:
- **From File Explorer:** Look directly in the left file tree for **`Calculator.apk`** or expand **`app`** to find **`app/Calculator.apk`**. You can right-click it and choose **Download**.
- **From AI Studio Toolbar:** Click the **Settings / Export** menu (or three vertical dots `⋮`) at the top right of the screen and choose **"Download APK"**.
